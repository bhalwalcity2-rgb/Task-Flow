# TaskFlow — Personal Productivity Dashboard

A premium, fully offline personal productivity dashboard built with vanilla HTML, CSS, and JavaScript. All data persists in LocalStorage — no backend, no login, no server required.

## Quick Start

1. Open `index.html` in any modern browser.
2. That's it. Everything works locally.

## Features (Planned)

| Phase | Features | Status |
|-------|----------|--------|
| 1 | Dashboard layout, sidebar, navbar, stat cards, responsive UI, dark mode | ✅ Done |
| 2 | Task CRUD, priority, status, due dates, filters, search, localStorage | 🔲 |
| 3 | Projects, calendar, countdown, notifications, notes | 🔲 |
| 4 | Kanban board, Chart.js reports, analytics | 🔲 |
| 5 | Settings, export/import, optimization, keyboard shortcuts | 🔲 |

## Tech Stack

- HTML5 / CSS3 / Vanilla JavaScript (ES6)
- LocalStorage for persistence
- Chart.js (Phase 4)
- FullCalendar (Phase 3)
- SortableJS (Phase 4)
